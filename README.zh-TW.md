---

**NewLife.IoT** 是物聯網標準函式庫——為 IoT 領域定義通訊協定的**統一契約**，不含具體協定實作。目標是成為 IoT 平台與硬體驅動程式之間的**單一抽象層**。

| 平台側 | 驅動側 | 設計亮點 |
|:---|:---|:---|
| 引用 `IDriver`/`INode`/`IDevice` —— 一套 API 操作所有硬體 | 繼承 `DriverBase` —— 接入平台生態 | 非同步優先 `Task<T>` + `CancellationToken` |
| 星塵、ZeroIoT、FIoT、自訂平台 | NewLife.Modbus、Siemens、OPC-UA、BACnet | `ReadResult` 攜帶品質碼/時間戳，`WriteResult` 零堆積配置 |
| `ThingSpec` 物模型 —— 屬性/事件/服務 | `ITransport` —— 統一序列埠/TCP/UDP/HTTP | 診斷幀開關，生產環境零開銷 |

| 原始碼 | NuGet | 文件 |
|------|-------|------|
| [GitHub](https://github.com/NewLifeX/NewLife.IoT) | [NewLife.IoT](https://www.nuget.org/packages/NewLife.IoT) | [需求文件](Doc/需求文档.md) · [功能清單](Doc/功能清单.md) · [架構設計](Doc/架构设计.md) |

**執行階段能力**：31 種語言本地化（與 NewLife.Core 詞表集對齊）· 帶實例前綴日誌 · NativeAOT 實測通過（20 場景，Windows/Linux/macOS）· 8 個目標框架（net45 → net10.0）。
